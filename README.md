# Denova

Sitio público de **Denova**, una plataforma en desarrollo para la gestión de clínicas dentales pequeñas en México.

## Sitio

Cuando GitHub Pages esté habilitado, la página se publicará desde `index.html`.

## Contenido

- `index.html`: presentación de Denova
- `privacy.html`: aviso de privacidad
- `terms.html`: términos del servicio
- `refunds.html`: política de cancelaciones y reembolsos
